# Android coursework starter project

Open this directory in Android Studio as a Gradle project. It contains a Java Android app implementing the coursework demos: AndroidX splash, UHC patient list/detail fragments, UgandaConnect service navigation and issue form, EcoUganda drawer/Navigation Component destinations and report deep link, WorkManager background refresh hook, App Startup Firebase hooks, and a ViewPager2 pager.

The task-by-task source map and explicit integration requirements are in [`../README.md`](../README.md). The assignment answer sheets are in [`../../tasks/`](../../tasks/). This project contains runnable demos and uses sample data where course credentials/datasets were not supplied.

Build from Android Studio or run `./gradlew assembleDebug`. Firebase features activate when you add this app's `google-services.json`; map/network services need valid service credentials/endpoints. The project compiled successfully to a debug APK during this work. It was not launched on a device/emulator.

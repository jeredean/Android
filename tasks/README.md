# Coursework answers

Each task has its own folder and answer sheet. The Android Studio project and task-by-task code maps are in the sibling `../work/` directory.

| Folder | Coverage |
|---|---|
| Task-01-Android-Splash-Screen-API | Splash implementation, memory leaks, Checkstyle, testing, and UI/UX questions |
| Task-02-Android-Fragments | UHC fragment design, optimization, lint, testing, and UI/UX |
| Task-03-04-Fragment-Theory | Both sets of Fragment theory questions |
| Task-05-Material-Design-Navigation-One | UgandaConnect bars, battery optimization, TDD, design, load-test plan |
| Task-06-Material-Design-Navigation-Two | EcoUganda drawer/navigation, startup optimization, device testing, theory |
| Task-07-ViewPager2-Theory | ViewPager2 theory questions |
| work/ | Android Studio project and per-task code maps |

Performance values that require a real device, profiler, or load test are left for measurement. The sheets give reproducible steps and result tables instead of made-up measurements.

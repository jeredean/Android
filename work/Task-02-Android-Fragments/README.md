# Task 2 — runnable code

Open [`../Android-Project`](../Android-Project) in Android Studio and run the `app` configuration. Choose **UHC Patients** in the drawer or bottom bar.

- `app/src/main/java/com/example/coursework/patients/PatientListFragment.java` — synthetic patient list, Activity-scoped `PatientSelectionViewModel`, phone detail navigation, and tablet two-pane behavior.
- `PatientDetailFragment.java` — synthetic summary/detail screen. The data is fictional and should not be replaced with real patient records in this demo.
- `PatientSelectionViewModel.java` — shared selection state.

The posted 500+ record benchmark, real JPEG assets, and 80 MB heap target require the course dataset and target device. This runnable demo uses five synthetic records and contains no clinical photos.
